# Float Batch 3 Visual QA Report: Model Picker v2

Conducted on macOS 14.x with Float debug build at commit `033d01b fix: preserve symlinked T3 settings`.
Screen session status: `CGSSessionScreenIsLocked: 1` (locked). Items requiring physical keyboard entry, hardware mouse hover, or system hotkey routing while locked are marked `Not checked (locked)` per instructions.

| Screenshot | State Shown | Mockup State | Result | Specific Reason |
| --- | --- | --- | --- | --- |
| `qa-05-default-tab-codex-bug.png` | Default opened tab upon pressing ⇧⌘M | Mockup state 5 | **Fail** | In `ModelMenuAnchor.swift:297-299`, `onAppear` tests `!providers.contains(where: { $0.instanceId == selectedTab })`. Because `providers` contains only model provider instances and does not include `"favourites"`, `selectedTab` is immediately overwritten with `providers.first?.instanceId` ("codex"). The picker fails to open on Favourites by default and always opens on the first provider tab. |
| `qa-05-favourites.png` | Favourites tab with model selected | Mockup state 5 | **Fail** | In `ModelMenuAnchor.swift:484-497`, `modelRow` checks `if hovered == model.selection || isFavourite` before checking `else if isCurrent`. Because every model in the Favourites tab has `isFavourite == true`, every row renders a blue `star.fill` button, and the current selected model (`isCurrent`) never receives the accent checkmark. |
| `qa-05-favourites.png` | Effort segmented control with 6 values | Mockup state 5 | **Fail** | When a Codex model with 6 reasoning effort values (`low`, `medium`, `high`, `xhigh`, `max`, `ultra`) is selected, the 20pt high segment buttons truncate label text into ellipses (`L...`, `M...`, `Hi...`, `XH...`, `Max`, `Ul...`) due to the fixed 290pt popover width. Mockup state 5 illustrates 4 readable segment values (`Low`, `Med`, `High`, `Max`). |
| N/A (State 5 Step 4) | Live hover revealing star on unstarred row | Mockup state 5 | **Not checked (locked)** | Live mouse hover and WindowServer tracking rects are blocked by `loginwindow` while screen is locked (`CGSSessionScreenIsLocked: 1`). Star toggling was verified programmatically to persist to `~/.t3/userdata/settings.json` and sync in both Float and T3. |
| `qa-06-provider-tab.png` | Codex provider tab with starred current model | Mockup state 6 | **Fail** | Active tab pill renders correctly (`Theme.text.opacity(0.09)`, 26pt height, 6pt radius) and refresh control (`arrow.clockwise`) sits at right edge of tab bar. However, the current model (`GPT-6.2 Sol`) displays `star.fill` instead of the accent checkmark because `isFavourite` overrides `isCurrent`. |
| `qa-06-unstarred-checkmark.png` | Provider tab with unstarred current model | Mockup state 6 | **Pass** | When an unstarred model (`GPT-6.1 Terra`) is selected as current, `isFavourite` is false and the row correctly renders the bold 10.5pt accent checkmark on the right edge. |
| `qa-06-provider-tab-antigravity.png` | Antigravity provider tab with Gemini 3.8 Flash | Mockup state 6 | **Fail** | Renders T3's official multi-colour `antigravity.png` icon and lists Antigravity models. The footer completely omits the effort selector row for Antigravity models. |
